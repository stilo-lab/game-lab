# /links – v1.5.9

Owner-only Übersicht aller Server des Bots.

## Nutzung
`/links`

Der Bot zeigt Servername, Server-ID und Invite-Link. Die Antwort ist nur für den Owner sichtbar.

## Benötigte Bot-Rechte
In mindestens einem Kanal pro Server: `Einladung erstellen` / Create Instant Invite.

Wenn diese Berechtigung fehlt, zeigt `/links` den Server trotzdem mit einer Warnung an.
